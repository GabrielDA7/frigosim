Logo officiel : déposer `logo.png` (fond transparent, ratio ≈ 3,4:1) ici, puis définir `NEXT_PUBLIC_BRAND_LOGO=/brand/logo.png` dans `.env.local`. L'enseigne murale l'affichera à la place du texte dessiné.
Couleurs de marque : variables `--brand` et `--brand-accent` dans `app/globals.css` (à aligner sur la charte L'atelier des Chefs).
